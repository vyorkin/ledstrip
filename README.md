# Цветомузыка: прошивка ATmega16 + WS2812

Три частотные полосы звука управляют тремя цветами адресной ленты:
низкие — красный, средние — зелёный, высокие — синий. Каждый цвет —
«пакет» из 20 соседних диодов, который бежит по всей ленте; яркость
пакета равна уровню своей полосы. Направление движения меняется на
каждом втором ударе по низкой полосе.

Полное описание: [GLOSSARY.md](GLOSSARY.md) (термины),
[docs/hardware.md](docs/hardware.md) (схема и подключение),
[docs/interface.md](docs/interface.md) (контракт прошивки и аналоговой части),
[docs/adr/](docs/adr/) (принятые решения).

## Что собрано

| Параметр | Значение |
|---|---|
| Микроконтроллер | ATmega16, кварц 16 МГц |
| Лента | WS2812/WS2812B, 120 диодов, 5 В |
| Кадр | 5 мс, 200 Гц |
| Пакет | 20 диодов на канал |
| Позиция пакета | 0…100 диодов (лента минус длина пакета) |
| Скорость | 30 диодов/с на канал (≈0.148 диода за кадр) |
| Сторожевой таймер | 2 с, сброс в каждом кадре |
| Питание ленты | 5 В, БП 10 А; текущие режимы — ~1 А, 7.2 А — расчётный максимум для всех 120 диодов белым |

## Сборка и прошивка

Нужны `avra` и `avrdude`; для сборки достаточно `make`.

```sh
cd firmware
make            # build/ledstrip.hex, .lst, .map
make flash      # avrdude -c usbasp -p m16 -U flash:w:build/ledstrip.hex:i
make fuses      # lfuse=0x3F, hfuse=0xCF (внешний кварц 16 МГц)
make check      # прогон в simavr: битовый поток, пакеты, удар, кнопка
```

`make check` нужен `simavr` (`pacman -S simavr` или AUR) и
`pkg-config`; без него собирается только прошивка.

Фьюзы: `lfuse = 0x3F` (внешний кварц 8–16 МГц, BOD включён на 4.0 В),
`hfuse = 0xCF` (JTAG выключен, SPIEN включён, BOOTRST выключен,
CKOPT=0 — полный размах генератора).
Для ATmega16 `CKSEL=1111` — внешний кварц 8–16 МГц; полный размах
генератора нужен на 16 МГц.

## Подключение

| Сигнал | Пин ATmega16 |
|---|---|
| Данные WS2812 | PB0 (через 330 Ом) |
| Огибающая низкой полосы | PA0 (ADC0) |
| Огибающая средней полосы | PA1 (ADC1) |
| Огибающая высокой полосы | PA2 (ADC2) |
| Кнопка смены режима | PD2, на GND (внутренняя подтяжка) |
| Питание | 5 В; GND общий с лентой |
| Кварц | XTAL1/XTAL2, 16 МГц |
| ISP | MOSI, MISO, SCK, RESET |

Данные ленты — 5 В, ATmega16 тоже 5 В, поэтому согласование не нужно.
Обязательны: электролит 1000 мкФ на питании ленты, резистор 330 Ом
последовательно с данными, общий провод контроллера и ленты.

## Управление

Кнопка PD2, короткое нажатие — следующий режим (по кругу):

| Режим | Красный | Зелёный | Синий |
|---|---|---|---|
| 0 | вправо | вправо | вправо |
| 1 | влево | вправо | влево |
| 2 | вправо | вправо (к центру) | влево (к центру) |
| 3 | вправо | влево (от центра) | вправо (от центра) |

«Вправо» — от начала ленты (разъём данных) к концу, «влево» — обратно.
Стартовые позиции пакетов: красный 10, зелёный 40, синий 80 (позиции 0…100 на ленте из 120 диодов).
Разворот на каждом втором ударе по низкой полосе применяется ко всем
пакетам сразу.

## Что крутить на стенде

Константы — в начале `firmware/src/main.asm`:

| Константа | Значение | Смысл |
|---|---|---|
| `NLED` | 120 | диодов в ленте; единственное число для смены длины |
| `PKT` | 20 | диодов в пакете |
| `HIT_DELTA` | 60 | прирост АЦП за кадр, считающийся ударом |
| `HIT_MIN` | 120 | уровень ниже этого удара не даёт |
| `REFRAC_FRAMES` | 40 | 200 мс тишины между ударами |
| `HIT_N` | 2 | разворот каждый второй удар |
| `MAXPOS` | `(NLED-PKT)*256` | предел позиции пакета (100.0 диодов в 8.8) |

Скорости и направления режимов — `mode_tab` в `firmware/src/tables.inc`.
Скорость задана в формате 8.8: 256 = 1 диод за кадр; 38 ≈ 0.148.
Если лента короче или длиннее, меняется только `NLED` в начале
`main.asm`: из него считаются буфер (`NBYTES`), предел позиции
(`MAXPOS`) и стартовые позиции (`START0..START2`). `PKT` меняют,
только если нужен другой пакет.

Яркость: таблица `gamma_tab` (`raw/4 → 0..204`) задаёт гейт шума
(индекс 10, сырой код 40), полную шкалу (индекс 180, 3.52 В) и гамму 1.8.
Если детектор на стенде даёт другой максимум, пересчитайте таблицу.

## Проверка

Прошивка собрана `avra` без ошибок: 580 слов кода, 384 байта SRAM
(`make` печатает те же числа). `make check` прогоняет её в `simavr`
(`pacman -S simavr` или AUR) и проверяет:
- ровно 360 байт в кадре, высокие импульсы 6/12 тактов при периоде
  20 тактов внутри байта, пауза сброса не короче 50 мкс;
- WDT включён с таймаутом 2 с и не сбрасывает МК за 2.25 с работы;
- при максимальных уровнях на PA0..PA2 пакеты стоят на 10/40/80 и
  имеют яркость 204, остальные диоды погашены;
- каждый второй удар низкой полосы разворачивает пакеты;
- кнопка PD2 переключает режим (в режиме 1 красный пакет идёт влево).

Стенд сам разбирает битовый поток в буфер, поэтому расхождение прошивки
с `gamma_tab`/`mode_tab` видно сразу. Для ручной проверки без звука
подайте на PA0..PA2 постоянные уровни 0…3.5 В — пакеты светятся
пропорционально; кнопка PD2 переключает режимы.
