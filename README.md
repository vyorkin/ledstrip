# Цветомузыка: STM32F411 + WS2812

Три частотные полосы звука управляют тремя цветами адресной ленты:
низкие — красный, средние — зелёный, высокие — синий. Каждый цвет —
пакет из 20 соседних диодов, который бежит по ленте; яркость пакета
равна уровню полосы. Направление меняется на каждом втором ударе по
низкой полосе.

Текущая версия — STM32F411: один вход АЦП, цифровые полосы, цифровая
АРУ, без аналогового компрессора и без 12 В. AVR-версия осталась
эталоном в `firmware/`, пока новая не проверена на столе.

[docs/hardware-stm32.md](docs/hardware-stm32.md) (схема и подключение),
[docs/interface-stm32.md](docs/interface-stm32.md) (контракт прошивки),

## Что собрано

| Параметр | Значение |
|---|---|
| Микроконтроллер | STM32F411CE, 100 МГц, 3.3 В |
| Вход | один линейный, 3.5 мм, PA1; смещение 1.65 В, делитель 0.4 |
| АЦП | один канал PA1 (ADC1), 96 кГц, 12 бит, таймер + DMA |
| Полосы | 141 Гц / 4.82 кГц / 13.2 кГц, цифровые biquad |
| АРУ | цифровая, общая для трёх полос, ×0.5…×8 |
| Компрессор | отсутствует |
| Аналоговые полосовые фильтры | отсутствуют, полосы только цифровые |
| Кадр | 5 мс, 200 Гц |
| Пакет | 20 диодов на канал |
| Позиция | 0…100 диодов (лента минус пакет) |
| Скорость | 30 диодов/с на канал (≈0.148 диода за кадр) |
| Лента | WS2812/WS2812B, 120 диодов, 5 В |
| Выход ленты | PB0, TIM3_CH3, DMA, 74AHCT1G125 (≈4.7 В) |
| Питание | 5 В, БП 10 А; 3.3 В — с платы |

## Состояние

- Схема и контракт описаны; все детали, кроме платы, есть.
- Плата WeAct STM32F411CE отсутствует: без неё целевая прошивка не
  проверена.
- `firmware-stm32` содержит host-тестируемое ядро DSP и кадров; оно
  собирается и проверяется обычным `cc`, без платы.
- `firmware-stm32/target` содержит bare-metal сборку: PLL 100 МГц на HSE
  25 МГц и heartbeat на PC13. Собирается `arm-none-eabi-gcc`; на железе
  ещё не проверена.
- АЦП/DMA, таймер WS2812, кнопка и watchdog появятся после платы: их
  нельзя проверить без осциллографа и ленты.

## Стенд: что нужно

- WeAct STM32F411CEU6 Black Pill — единственная обязательная покупка,
  платы пока нет.
- ST-Link по SWD для прошивки и отладки.
- `arm-none-eabi-gcc` для целевой сборки; host-ядро собирается обычным
  `cc`.
- MCP6004, 74AHCT1G125, 330 Ом, BAT54S, конденсаторы 100 нФ/1 мкФ/
  10 мкФ/680 пФ/330 пФ, резисторы 15 кОм/10 кОм/1 кОм, 1000 мкФ
  у ленты.
- БП 5 В 10 А, лента WS2812 на 120 диодов, разъёмы и общий провод.
- Подробности сборки и проверки — в
  [docs/hardware-stm32.md](docs/hardware-stm32.md).

## Сборка ядра

```sh
cd firmware-stm32
make test
```

Нужны `cc`, `make` и `libm` (на Arch — `base-devel`). Тест проверяет:

- АЧХ трёх полос: тон 141 Гц / 4.82 кГц / 13.2 кГц открывает свой канал
  сильнее остальных;
- АРУ: тихий и громкий тон дают сопоставимую яркость без переполнения;
- удар: шесть низкочастотных вспышек дают шесть ударов с паузой 200 мс;
- кадр: 360 байт, пакеты на стартовых позициях, отражение от краёв,
  смена режима, `flip` каждый второй удар.

## Сборка прошивки

```sh
cd firmware-stm32
make target   # ELF/HEX/BIN + карта и занятая память
make check    # host smoke-проверка целевого дерева
make flash    # st-flash write ... 0x08000000
```

Нужны `arm-none-eabi-gcc` и `stlink`. Подробности, ожидаемый результат и
проверка тактирования — в
[firmware-stm32/target/README.md](firmware-stm32/target/README.md).

## Подключение

| Сигнал | Пин STM32F411 |
|---|---|
| Линейный вход | PA1 (ADC1), единственный аудиовход |
| Данные WS2812 | PB0 (TIM3_CH3) через 74AHCT1G125 и 330 Ом |
| Кнопка | PA0, на GND (внутренняя подтяжка) |
| Светодиод платы | PC13 |
| Свободные пины | PA2, PA3 (не используются) |
| Питание | 5 В, GND общий с лентой |
| Отладка | SWD: PA13/PA14 |

Вход: C1 1 мкФ → R1 15 кОм → R2 10 кОм на смещение 1.65 В → буфер
MCP6004 → Sallen-Key 33.6 кГц → BAT54S и 100 нФ на PA1. Делитель 0.4
превращает 2 В rms в 2.26 В размаха вокруг 1.65 В. Аналогового
компрессора нет; от клиппинга защищают делитель и BAT54S, громкость
выравнивает цифровая АРУ.

WS2812: 5 В, 1000 мкФ на ленте, 330 Ом последовательно с данными,
74AHCT1G125 питается от 5 В и согласует 3.3 В → высокий уровень
≈4.7 В. Не подавайте 5 В на пин 5V платы одновременно с USB.

## Управление

Кнопка PA0, нажатие 25 мс — следующий режим (по кругу). Режимы и
направления не менялись относительно AVR:

| Режим | Красный | Зелёный | Синий |
|---|---|---|---|
| 0 | вправо | вправо | вправо |
| 1 | влево | вправо | влево |
| 2 | вправо | вправо (к центру) | влево (к центру) |
| 3 | вправо | влево (от центра) | вправо (от центра) |

«Вправо» — от начала ленты к концу. Стартовые позиции: красный 10,
зелёный 40, синий 80. Смена режима — сразу, `flip` и счётчик ударов
не сбрасываются; после сброса режим 0, в память не пишется.

## Что крутить

Константы — в `firmware-stm32`:

| Константа | Где | Смысл |
|---|---|---|
| `DSP_BANDS` | `include/ledstrip/dsp.h` | число полос |
| `DSP_FRAME_SAMPLES` | `include/ledstrip/dsp.h` | 480 отсчётов на кадр |
| `DSP_BRIGHT_MAX` | `include/ledstrip/dsp.h` | 204 (80 %) |
| `FRAME_NLED` | `include/ledstrip/frame.h` | 120 диодов |
| `FRAME_PKT` | `include/ledstrip/frame.h` | 20 диодов |
| `FRAME_SPEED` | `include/ledstrip/frame.h` | 38 (8.8) |
| `BEAT_DELTA` / `BEAT_MIN` | `src/dsp.c` | порог удара |
| `AGC_TARGET` / `AGC_MAX` | `src/dsp.c` | цель и предел АРУ |

Границы полос и Q — в `dsp_init()` (`src/dsp.c`). Скорость и стартовые
позиции — в `frame_init()` (`src/frame.c`).

## AVR-эталон

`firmware/` не удаляется до проверки STM32 на реальной ленте и звуке.

```sh
cd firmware
make            # build/ledstrip.hex, .lst, .map
make flash      # avrdude -c usbasp -p m16 -U flash:w:build/ledstrip.hex:i
make fuses      # lfuse=0x3F, hfuse=0xCF
make check      # simavr: битовый поток, пакеты, удар, кнопка
```

AVR: ATmega16, 16 МГц, три входа АЦП, аналоговые полосы и компрессор.
Схема — `docs/hardware.md`, контракт — `docs/interface.md`, решение —
`docs/adr/0001-analog-band-split.md` (superseded).
