# Контракт: прошивка STM32F411 ↔ вход и лента

Текущая версия. Решение — [ADR 0002](adr/0002-digital-band-split-stm32.md).
AVR-контракт с тремя аналоговыми входами остался в [interface.md](interface.md)
как эталон ([ADR 0001](adr/0001-analog-band-split.md), superseded); для новой
платы он не используется.

## АЦП

| Параметр | Значение |
|---|---|
| Вход | PA1 (ADC1), один канал; PA2/PA3 не используются |
| Опора | 3.3 В, VREF+ = VDDA |
| Разрядность | 12 бит |
| Частота | 96 кГц |
| Запуск | таймер, TRGO |
| Передача | DMA, циклический буфер |
| Смещение | 1.65 В, размах до 2.8 В |

Отсчёт приводится к `[-1, 1]` как `(adc - 2048) / 2048`. Постоянная
составляющая дополнительно убирается цифровым ФВЧ с полюсом около
15 Гц. Вход выше 3.3 В не допускается; от клиппинга защищают делитель
0.4 и BAT54S.

## Цифровая обработка

Один поток отсчётов 96 кГц проходит через три параллельных biquad
band-pass:

| Канал | f0 | Q | Границы −3 дБ |
|---|---|---|---|
| Красный, низкая | 141 Гц | 1.46 | 101…197 Гц |
| Зелёный, средняя | 4.82 кГц | 1.54 | 3.50…6.62 кГц |
| Синий, высокая | 13.2 кГц | 1.12 | 8.60…20.4 кГц |

Фильтры — RBJ band-pass с усилением 1 на центральной частоте. После
каждого фильтра — точный выпрямитель и огибающая:

- атака 2 мс;
- спад 150 мс;
- огибающая хранится в линейном масштабе.

## АРУ

Общая для трёх полос цифровая АРУ:

- цель — пик 0.5 полной шкалы;
- усиление ограничено 0.5…8.0 (от −6 до +18 дБ);
- спад усиления (громче) — 50 мс, возврат (тише) — 500 мс;
- при пике ниже 0.01 усиление не растёт, чтобы не поднимать шум.

АРУ умножает огибающие всех полос на одно и то же число, поэтому
соотношение цветов не меняется. Это не аналоговый компрессор: от
клиппинга АЦП она не защищает.

## Яркость и удар

Яркость канала:

```
level = clamp(env * agc_gain, 0, 1)
brightness = 204 * (level / 0.5)^1.8
```

`brightness` ограничена 0…204 (80 % от 255). Ниже 0.02 — ноль, чтобы
не светить шум.

Удар считается по низкой полосе на кадре 200 Гц:

- прирост уровня за кадр больше 0.05;
- текущий уровень больше 0.12;
- с прошлого удара прошло не меньше 40 кадров (200 мс).

Первый кадр только запоминает уровень. Удар переключает `flip` каждый
второй раз; счётчик при смене режима не сбрасывается.

## Кадр и режимы

Кадр — 200 Гц (5 мс), 120 диодов, 20 диодов в пакете, позиция 0…100
в формате 8.8, скорость 38 (≈0.148 диода за кадр, 30 диодов/с),
стартовые позиции 10/40/80. Режимы и кнопка не меняются относительно
AVR-версии:

| Режим | Красный | Зелёный | Синий |
|---|---|---|---|
| 0 | вправо | вправо | вправо |
| 1 | влево | вправо | влево |
| 2 | вправо | вправо (к центру) | влево (к центру) |
| 3 | вправо | влево (от центра) | вправо (от центра) |

«Вправо» — от начала ленты к концу. Кнопка PA0: 5 подряд кадров
нажатия (25 мс), затем следующий режим сразу; отпускание сбрасывает
счётчик. После сброса режим 0, в память не пишется.

## WS2812

| Параметр | Значение |
|---|---|
| Пин | PB0, TIM3_CH3, AF2 |
| Частота таймера | 100 МГц |
| Период | 125 тиков, 800 кГц |
| CCR | 38 для 0, 75 для 1 |
| T0H / T0L | 0.38 / 0.87 мкс |
| T1H / T1L | 0.75 / 0.50 мкс |
| DMA | DMA1 Stream 2, канал 5, запрос по обновлению TIM3 |
| Буфер | 2880 полуслов DMA |
| Кадр | 360 байт, GRB, MSB первым |
| Время кадра | 3.6 мс |
| Пауза сброса | ≥50 мкс |

Контракт `docs/interface.md` задаёт T0H 0.375, T1H 0.75, T0L 0.875,
T1L 0.5 мкс. T0H — 37.5 тика, поэтому взят 38 (0.38 мкс); остальные
три значения точные. Решение и причина — [ADR 0003](adr/0003-ws2812-timing.md).

Первое полуслово загружается программным `UG` до запуска счётчика,
остальные 2879 — по обновлению таймера после каждого бита: всего 2880
передач DMA. После спада последнего бита прошивка останавливает TIM3 с
`CCR3 = 0`, поэтому PB0 уходит в ноль без короткого импульса и остаётся
низким на паузе сброса. CPU только запускает DMA и ждёт флаги, биты не
выдаёт.

При старте PB0 сначала принудительно низкий, затем отправляется нулевой
кадр, пауза ≥50 мкс и только потом тестовый рисунок. При отказе PLL
(HSI fallback) кадр не отправляется: неверная битовая скорость не
должна попасть на ленту.

Преобразователь уровня 74AHCT1G125 питается от 5 В, вход 3.3 В,
высокий уровень на выходе ≈4.7 В, `OE` на GND. Последовательно
с данными — 330 Ом.

## Кнопка и светодиод

- PA0 — штатная кнопка Black Pill, активный низкий, внутренняя подтяжка.
- PC13 — штатный светодиод, активный низкий; мигает в простое, если
  нужно.

## Тесты

`firmware-stm32/test` собирается обычным `cc` без платы:

- АЧХ трёх полос: тон на 141 Гц / 4.82 кГц / 13.2 кГц открывает свой
  канал сильнее остальных;
- АРУ: тихий и громкий тон дают сопоставимую яркость без переполнения;
- удар: синтетические низкочастотные вспышки дают удары с паузой 200 мс;
- кадр: 360 байт, пакеты на стартовых позициях, отражение от краёв,
  смена режима и `flip` каждый второй удар;
- WS2812: 360 байт GRB → 2880 полуслов, MSB первым, 0 → 38, 1 → 75.

Проверка на железе: осциллограф на PA1 (смещение 1.65 В), на PB0
(≈4.7 В, T0H/T1H), кнопка и лента. HIL-тестов нет.
