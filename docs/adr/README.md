# Architecture Decision Records

| ADR | Статус | Решение |
|---|---|---|
| [0001](0001-analog-band-split.md) | superseded | Аналоговое деление спектра на ATmega16: три входа АЦП, компрессор, полосовые фильтры. Только AVR-эталон. |
| [0002](0002-digital-band-split-stm32.md) | accepted | STM32F411: один вход АЦП PA1, цифровые полосы и АРУ. Текущее решение. |
| [0003](0003-ws2812-timing.md) | accepted | WS2812 на STM32: CCR 38/75, тайминг как у AVR-эталона. Заменяет CCR 50/100 из #1. |

Текущий дизайн определяется ADR 0002 и ADR 0003. ADR 0001 сохранён для AVR-версии
в `firmware/` и к новой сборке не применяется.
